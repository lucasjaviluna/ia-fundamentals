# Taller técnico

Prácticas cortas e independientes para pasar de los conceptos de la web a código ejecutable. Cada práctica declara requisitos y ofrece ejercicio, solución y pruebas.

| Práctica | Qué vas a aprender | Estado |
|---|---|---|
| [01 · Tokenización](01-tokenization/README.md) | Comparar textos e IDs con una codificación real | Disponible |
| [02 · Prompt engineering](02-prompt-engineering/README.md) | Comparar prompts en vivo y comprobar respuestas | Disponible |
| 03–12 · APIs, herramientas, agentes, MCP, RAG y evaluación | Ver [plan integral](../docs/PLAN_IMPLEMENTACION.md) | Pendientes |

Comenzá por la práctica 01; no se necesitan credenciales. Los tiempos son orientativos y pueden ajustarse durante el taller.
